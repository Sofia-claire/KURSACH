
# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
## Кроссплатформенное приложение «Умный Эксель» (Smart Excel)
### Введение
Настоящее руководство пользователя предназначено для аналитиков данных, операторов ETL и сотрудников, осуществляющих консолидацию и очистку табличных отчётов форматов .xlsx и .xls.
### Назначение системы
Приложение «Умный Эксель» предназначено для автоматизации сведения разрозненных таблиц, удаления дубликатов, обработки пустых ячеек и интеллектуального сопоставления записей с опечатками или инверсией слов на основе алгоритма расстояния Левенштейна.
### Начало работы
#### Запуск системы
##### Вариант 1: Запуск локального скомпилированного файла (Рекомендуемый для пользователей)
 1. Перейдите в папку dist/.
 2. Запустите исполняемый файл SmartExcel.exe.
##### Вариант 2: Запуск среды разработки и тестов через Docker
Если проект разворачивается в изолированном контейнере, выполните команду в терминале:
docker compose up --build
#### Авторизация в системе
При старте приложения открывается защищённое окно авторизации.
 1. Введите учётные данные:
   * Логин: admin
   * Пароль: admin_password
 2. Нажмите кнопку «Войти».
   *Примечание: Пароли хэшируются по алгоритму SHA-256 с солью, обеспечивая безопасность данных.*
### Работа с интерфейсом и сценарии
Основной интерфейс приложения разделен на три логические зоны: Панель импорта, Настройки алгоритма и Окно предпросмотра результатов.
#### Шаг 1: Загрузка и ETL-очистка файлов
 1. В панели управления нажмите кнопку «Открыть файл Excel» (или «Выбрать эталонную таблицу»).
 2. Через проводник ОС выберите целевой файл формата .xlsx или .xls.
 3. Система автоматически запустит Pandas-пайплайн: удалит дубликаты строк, очистит лишние пробелы и преобразует пустые ячейки (NaN) в нулевые или пустые значения.
#### Шаг 2: Настройка нечёткого поиска (Алгоритм Левенштейна)
Для сопоставления строк с опечатками (например, *"ООО МТС"* и *"ОАО М.Т.С."*):
 1. С помощью интерактивного ползунка (Slider) в GUI установите Порог схожести (рекомендуемое значение — 85%).
 2. Нажмите кнопку «Запустить сопоставление».
 3. Программа визуализирует процесс обработки через индикатор загрузки (ProgressBar).
#### Шаг 3: Разрешение коллизий и экспорт
 * Просмотр результатов: Связанные строки отобразятся в общей таблице интерфейса. Строки, не прошедшие порог совпадения, маркируются как «Коллизии».
 * Экспорт отчета: Нажмите кнопку «Сохранить результат». Выберите путь на диске — программа сформирует идеально чистый файл .xlsx и параллельно запишет транзакцию в локальную базу данных SQLite.
### Работа с автоматическими тестами (для администраторов)
Для проверки целостности ядра и базы данных настроена автоматическая система тестирования.
 * Запуск тестов в консоли:
  
   python -m pytest -v
   
   
 * Просмотр покрытия кода: Запустите тесты с флагом покрытия, после чего откройте сгенерированный файл ./cov_html/index.html в любом браузере для просмотра интерактивного отчета.
### Типичные ошибки и их устранение

| Ситуация | Возможная причина | Способ решения |
| :--- | :--- | :--- |
| Ошибка авторизации (Invalid Credentials) | Введен неверный логин/пароль или база данных SQLite заблокирована другим процессом. | Проверить раскладку клавиатуры и Caps Lock. Убедиться, что файл database.db не открыт в сторонних редакторах СУБД. |
| Приложение падает при импорте файла | Файл Excel имеет поврежденную структуру или защищен паролем. | Открыть файл в Microsoft Excel / LibreOffice, пересохранить как «Книга Excel (.xlsx)» без защиты и повторить импорт. || Слишком мало совпадений в таблице | Завышен порог схожести в алгоритме Левенштейна. | Сдвинуть ползунок порога схожести до 70% - 75% и запустить процесс заново. |
| Ошибка сборки Docker-контейнера | Порты заняты или отсутствует интернет-соединение для скачивания библиотек. | Выполнить docker compose down, проверить интернет и перезапустить сборку. |

### Завершение работы
Для закрытия приложения просто нажмите на крестик в правом верхнем углу GUI-окна. Все несохраненные в SQLite сессии будут сброшены для безопасности.
### Используемые сокращения
 * GUI — Графический интерфейс пользователя (CustomTkinter).
 * ETL — Процесс извлечения, преобразования и загрузки данных.
 * Коллизия — Ситуация, при которой две строки имеют коэффициент схожести ниже установленного порога и требуют ручной проверки.
