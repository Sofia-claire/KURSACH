# Smart Excel (Умный Эксель)

## Введение
Кроссплатформенное десктопное приложение для автоматизации консолидации, очистки и нечёткого сопоставления табличных данных из различных отчётных форм Excel. 

Проект разработан в рамках курсового проектирования с упором на автоматизацию ETL-процессов, контейнеризацию и обеспечение качества через CI/CD пайплайны.

## Основной функционал
* **Нечёткое сопоставление строк:** Интегрирован алгоритм на основе расстояния Левенштейна для автоматического связывания записей с опечатками, разным регистром или инверсией слов.
* **ETL и Валидация (Pandas):** Автоматическая очистка входящих файлов от дубликатов, обработка пустых ячеек (NaN) и приведение типов к единому стандарту.
* **Локальное хранилище (SQLite):** Быстрая реляционная база данных для персистентного хранения сопоставленных данных и логов ошибок с контролем уникальности записей.
* **Современный GUI:** Интерфейс выполнен на библиотеке `CustomTkinter` с поддержкой темного/светлого режимов адаптивного дизайна.
* **Автоматическое тестирование:** Полное покрытие критических узлов (алгоритм Левенштейна, парсер Pandas, транзакции базы данных) юнит-тестами.

## Требования к системе
* **Python:** Версия 3.10 или выше.
* **Зависимости:** Полный список библиотек указан в файле `requirements.txt` (включая `pandas`, `customtkinter`, `pytest`).

## Варианты запуска проекта

Вы можете запустить проект тремя способами: как локальный скрипт, через Docker-контейнер или скомпилированный бинарный файл.

### Вариант 1: Локальное виртуальное окружение (Разработка)

1. Создайте и активируйте виртуальное окружение:
bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Linux/MacOS:
   source .venv/bin/activate
 2. Установите зависимости:
bash
   pip install -r requirements.txt
 3. Запустите приложение:
bash
   python main.py### Вариант 2: Запуск в Docker-контейнере
Проект полностью контейнеризирован, что исключает проблемы с несовместимостью окружения.
 1. Сборка и запуск контейнера:
bash
   docker compose up --build### Вариант 3: Готовый исполняемый файл (.exe)
Для конечных пользователей в каталоге dist/ доступен скомпилированный установщик, не требующий наличия Python на компьютере.
*(Инструкция по пересборке .exe через PyInstaller находится в документации разработчика).*
## Автоматическое тестирование (QA)
В проекте реализовано модульное тестирование с использованием фреймворка pytest. Тесты проверяют три критических бизнес-сценария на искусственном «грязном» датасете:
 1. Корректность работы алгоритма нечёткого поиска при наличии ошибок в строках.
 2. Стойкость парсера Pandas к пустым ячейкам и дубликатам.
 3. Целостность транзакций в SQLite.
### Запуск тестов локально:
bash
python -m pytest -v
### Запуск тестов с генерацией отчета о покрытии кода (Code Coverage):
bash
python -m pytest --cov-report html:cov_html --cov=.
Результаты покрытия будут сохранены в папку ./cov_html.
## Структура репозитория
 * /src или main.py — Исходный код приложения.
 * /tests — Пакет автоматических юнит-тестов (pytest).
 * /docs — Техническое задание (ТЗ) и методология разработки.
 * Dockerfile & docker-compose.yml — Конфигурация контейнеризации.
 * requirements.txt — Список внешних зависимостей.
